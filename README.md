# 搬瓦工退款政策：30天退款条件、申请流程与套餐购买前的避坑说明

搜索“搬瓦工退款政策”的人，通常不是只想知道“能不能退”。更实际的问题是：**退款期限从什么时候开始算、续费能不能退、IP 被封还能不能退、申请退款会不会删除服务器数据，以及到底应该通过哪里提交申请。**

搬瓦工，也就是 BandwagonHost，官网目前仍然提供 **30 天退款保障**，但它不是无条件退款。官方服务条款列出了多项限制，包括新订单期限、账户状态、IP 黑名单、流量使用量和退款申请次数等。满足条件时，官方会全额退还账户付款，但会立即终止账户下的服务，并删除 VPS、快照和备份数据。

下面按实际操作顺序说明。

## 搬瓦工退款政策先看结论

截至 **2026 年 9 月 30 日**，搬瓦工官网公开信息可以归纳为以下几点：

- 新订单通常可以在下单后 **30 天内**申请退款。
- 退款对象必须是新订单，**续费订单不符合官方退款条件**。
- 账户需要处于正常状态，没有逾期账单，也不能违反服务条款。
- 付款不能存在 PayPal 争议、信用卡拒付或 chargeback。
- 分配给 VPS 的 IP 地址不能在黑名单或封禁名单中。
- VPS 月度流量使用量必须低于套餐月度流量额度的 **10%**。
- 退款申请次数不能被认定为过多或滥用。
- 申请成功后，账户下相关服务会立即终止。
- VPS 中的数据、快照和备份会被立即且不可逆地删除。
- 退款只能退回到原付款方式。
- 官方知识库提供退款申请入口，提交后系统会把请求转交账务部门处理。

所以，“30 天无理由退款”这个说法需要稍微修正。它更准确的表达是：

> 搬瓦工提供 30 天退款保障，但申请必须同时满足服务条款中的全部条件。

## 搬瓦工 30 天退款从哪一天开始计算？

官方条款使用的是“新订单下单不超过 30 天”的表述。实际判断时，建议按照订单创建时间计算，而不是按照你第一次登录 KiwiVM、第一次连接服务器或第一次部署网站的时间计算。

举例来说：

- 9 月 1 日创建新 VPS 订单，通常应在 10 月 1 日前提交退款申请。
- 9 月 1 日创建订单，9 月 20 日重装系统，不会重新获得一个新的 30 天期限。
- 9 月 1 日购买一年套餐，10 月之后才发现不合适，通常不能因为套餐还有 11 个月未使用就要求按比例退款。
- 续费发生后，续费账单不属于官方条款中可以申请退款的新订单。

官方页面没有把“30 天”解释为每次续费后重新计算，因此不要把续费当成新的退款周期。服务条款明确要求退款服务必须是 **new order，而不是 renewal**。

## 哪些情况通常符合退款条件？

### 1. 新购买的 VPS 仍在 30 天内

这是最基本的条件。退款申请针对的是新订单，而不是续费、升级或历史服务的剩余时间。

如果只是购买后发现：

- 配置不够用；
- 机房位置不合适；
- 网络延迟不符合预期；
- 系统环境不适合自己的项目；
- 自己不会管理 Linux VPS；
- 网站暂时没有上线；

这些情况本身不一定会阻止你申请退款，但仍需同时满足其他条件，例如 IP 没有进入黑名单、流量使用没有超过限制。

### 2. 账户没有欠款或服务条款违规

官方要求账户处于 good standing，也就是没有逾期账单，并且没有违反服务条款。

搬瓦工是自管理 VPS。官方不会负责替用户安装应用、配置网站、排查应用程序问题、恢复用户备份或管理 VPS 内部软件。服务条款也要求用户具备独立管理 Linux 系统的基本能力。

这意味着：

- 因为不会配置 Nginx，不代表官方一定承担技术故障责任；
- 因为 Docker 容器配置错误，不代表可以自动退款；
- 因为应用程序崩溃，不等于主机服务本身违反承诺；
- 使用服务器进行条款禁止的活动，可能影响退款资格。

### 3. IP 没有被列入黑名单

这是搬瓦工退款政策中比较容易被忽略的一条。

官方条款要求，申请退款时分配给 VPS 的 IP 地址不能位于任何 blacklist 或 blocklist 中。如果 IP 曾经因为被列入黑名单而被官方更换，也可能影响退款资格。官方还直接说明：如果分配给 VPS 的 IP 被列入黑名单，不会因此提供退款。

因此，购买 VPS 后不要立刻进行高风险操作。尤其要避免：

- 垃圾邮件群发；
- 大量营销邮件；
- 端口扫描；
- DoS 或其他攻击；
- 开放代理；
- BitTorrent；
- 恶意软件传播；
- 未经授权的爬虫或数据采集；
- 加密货币挖矿；
- 运行开放 DNS、开放 NTP 等可能造成放大的服务。

这些行为可能触发封禁、暂停服务或 IP 进入黑名单。即使服务器本身没有使用多久，退款也不一定还能通过。

### 4. 流量使用量低于月度额度的 10%

官方要求，申请退款时 VPS 的月度数据传输使用量低于套餐月度配额的 10%。

这条限制非常实际。比如：

- 1 TB 月流量套餐，使用量应低于约 100 GB；
- 2 TB 月流量套餐，使用量应低于约 200 GB；
- 3 TB 月流量套餐，使用量应低于约 300 GB。

这里的“低于 10%”不是“使用超过 10% 也可以退款”，而是官方条款中的明确条件。为了避免争议，如果你只是试用，最好先完成系统登录、网络测试和基础部署，不要先把大量文件同步到服务器，也不要用它跑长时间下载、视频分发或大规模爬取任务。

需要注意，流量低于 10% 只是退款条件之一。满足流量限制，并不代表 IP 黑名单、订单类型和账户状态等其他条件可以忽略。

## 哪些情况通常不能退款？

### 续费订单

这是最明确的一种情况。官方条款要求服务必须是新订单，且不是 renewal。

如果你购买了年付套餐，使用一段时间后忘记取消自动续费，续费账单产生后再申请退款，不能简单按照“还没怎么使用”来判断。更稳妥的做法是：

1. 进入账单或服务管理页面；
2. 提前关闭自动续费；
3. 记录当前服务的到期时间；
4. 不要等到续费成功后再处理。

官方同时允许用户随时在账单门户取消服务续费，但“取消续费”和“退还已经产生的续费账单”是两件不同的事情。

### IP 已经被拉黑

如果 VPS IP 进入黑名单，官方条款明确表示不会因此退款。这个规则意味着，不能先进行可能导致 IP 被封的操作，之后再把 IP 问题当作退款理由。

如果你购买搬瓦工主要是为了对外提供网站、API 或邮件服务，应该在购买后先检查 IP 声誉、邮件端口和业务可用性，并控制初始流量。

### 账户违反服务条款

服务条款禁止垃圾邮件、攻击、挖矿、开放代理、BitTorrent、恶意软件、未经授权的内容分发等活动。官方可以暂停或终止违反条款的账户，且相关账户可能不符合退款条件。

### 已经发起拒付或 PayPal 争议

不要把信用卡拒付或 PayPal dispute 当作普通退款入口。

官方说明，发起拒付或 PayPal 争议可能导致名下账户被暂停，直到争议解决。官方还保留追缴拒付手续费和处理争议所产生费用的权利，条款列出了每小时 40 美元、按 15 分钟计费的处理费用。

如果确实想退款，先使用官方退款流程。直接发起拒付，往往会让问题变复杂。

### 频繁申请退款

官方条款要求退款请求不能过多或具有滥用性质。也就是说，多个关联账户反复购买、使用后退款，可能被认定为滥用退款政策。

这条规定没有公布具体次数阈值，因此不能把“30 天退款”理解为可以反复测试不同套餐、不同账户而不受限制。

## 搬瓦工退款怎么申请？

官方知识库给出的方式是进入退款申请页面。知识库说明，提交申请后，系统会代表用户向账务部门创建退款请求。

建议按下面的顺序处理。

### 第一步：确认订单类型和时间

先确认：

- 是否为新订单；
- 是否在下单后 30 天内；
- 是否已经产生续费；
- 是否有多个服务或关联账户。

如果你只是想停止以后自动扣款，优先取消续费，不要直接提交退款申请。

### 第二步：备份所有重要数据

退款成功后，官方会立即终止账户下的相关服务，并删除 VPS 数据、快照和备份。这个删除是不可逆的。

在提交退款前，至少检查：

- 网站文件；
- 数据库；
- SSL 证书；
- DNS 配置；
- 环境变量；
- SSH 密钥；
- 定时任务；
- Docker 镜像和配置；
- KiwiVM 快照；
- 外部备份。

不要把“官方有自动备份”理解成“退款后还能恢复”。退款条款已经明确写明，相关数据和备份会被删除。

### 第三步：检查流量和 IP 状态

在 KiwiVM 或客户端管理页面查看：

- 当前月流量使用量；
- IP 是否被替换过；
- IP 是否存在黑名单问题；
- 是否开启了可能持续消耗流量的任务；
- 是否有异常进程或异常外联。

如果使用量已经接近 10%，继续运行服务可能让退款条件变得更不利。

### 第四步：通过官方退款入口提交

官方知识库展示了 30 天退款说明和退款申请入口。退款请求提交后会进入账务部门处理。

申请时建议保留：

- 订单号；
- 服务名称；
- 账户邮箱；
- 申请时间；
- 退款原因；
- 付款方式；
- 工单编号或页面截图。

退款理由不需要写成长篇说明。写清楚订单号、服务名称和希望退款的对象即可，重点是确保账户和订单满足条款条件。

### 第五步：等待原付款方式退回

官方规定退款只能退回原付款方式。也就是说，不能要求改退到另一个 PayPal 账户、银行卡或其他账户。

官方公开条款没有承诺一个固定的到账小时数，因此不要把“提交申请”和“银行到账”当成同一个时间点。实际到账时间还可能受到支付渠道和银行处理速度影响。

## 搬瓦工退款前的检查清单

提交退款之前，可以按这个顺序检查：

1. **确认订单是新订单，不是续费订单。**
2. **确认下单时间没有超过 30 天。**
3. **确认账户没有逾期账单。**
4. **确认没有违反服务条款。**
5. **确认 IP 没有进入黑名单，也没有因黑名单被官方更换过。**
6. **确认月度流量使用量低于套餐额度的 10%。**
7. **确认没有发起 PayPal 争议或信用卡拒付。**
8. **备份 VPS、数据库、快照和配置文件。**
9. **提交申请后，不要继续依赖这台 VPS 运行生产服务。**
10. **保存退款申请记录和订单信息。**

其中第 8 步最容易被忽略。退款成功后，官方会立即终止账户下服务，并删除数据、快照和备份。这个结果不是“停止续费”，也不是“暂时关机”，而是服务和数据都会被清理。

## 搬瓦工退款政策到底宽不宽松？

从时间窗口看，30 天退款对新用户比较友好；从条件看，它并不是可以随意反复试用的无条件保证。

比较合理的理解是：

- 只想测试系统、线路和基础性能，可以选择低价套餐，控制流量和使用时间；
- 需要部署生产网站，应先确认数据备份、IP 状态和服务条款；
- 需要长期使用，最好先关闭自动续费提醒，避免续费后再处理；
- 需要高流量或企业级 SLA，应直接按业务要求选择套餐，不要先购买低配方案再期待通过退款解决所有问题；
- 如果你无法独立管理 Linux VPS，退款政策也不能弥补自管理服务的学习成本。

搬瓦工官方目前的核心规则很清楚：**新订单、30 天内、账户正常、IP 没有黑名单、流量低于 10%、没有拒付或滥用行为，才有机会获得全额退款。**符合条件时，退款会退回原付款方式；但服务终止和数据删除也会同时发生。
